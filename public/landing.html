Features

Everything you need to trust your prompts

Stop eyeballing chat answers. Turn your expectations into a repeatable test suite.

🧠

Grades by meaning

An AI judge compares what both answers mean. “Order number” and “order ID” are the same request. A changed number or condition is not.

🔍

Regression finder

Compare two runs side by side. See which cases passed before and fail now, with both outputs and the reason.

🧪

Six kinds of checks

LLM judge, keywords, contains, exact match, regex and JSON validity. Combine them on a single case.

🚦

CI quality gate

Fail the pull request when the pass rate drops or any case regresses. Results land in your GitHub summary.

💸

Cost and latency

Every run reports tokens, p95 latency and cost, so you can compare a cheaper model with confidence.

🔐

Your keys stay yours

API keys are encrypted with AES-256-GCM and never sent back. Private network addresses are blocked on public servers.

How it works

From idea to verdict in three steps

No code required. Use the dashboard, a CSV file, or the API.

Connect your AI

Add an API key and a model with an optional system prompt. That is a target.

Import your cases

Upload a CSV of questions and the answers you expect. Rows with an expected answer are judged by meaning automatically.

Run and compare

Start a run, then compare it with the last one to see exactly what improved and what broke.

Semantic judging

Different words. Same answer.

A literal check fails a perfectly good reply. The judge writes down what each side means first, then decides, so you can read its reasoning on every case.

✓ Passes“Could you provide your order number or purchase email?” matches “Please provide your order ID.”
✗ Fails“Refunds within 30 days” does not match “Refunds within 7 days.”
Built-in judge checkTest a model on six known examples before you trust it to grade your suite.
CI gate

Block bad prompts before they ship

Run the same suite on every pull request. The CLI exits with a failing code when quality drops, so a regression can never merge quietly.

# fails the build if quality drops
node bin/evalboard.mjs run \
  --suite "Support questions" \
  --target "Support bot" \
  --system-prompt-file prompts/support.txt \
  --baseline latest \
  --fail-under 0.85 \
  --max-regressions 0
Quick start

Running in two minutes

You need Node.js 22 or newer. Docker works too.

Run locally

# install and set an encryption key
npm install
cp .env.example .env
npm run gen-key   # paste into ENCRYPTION_KEY

# optional: load sample data
npm run seed

# start, then open localhost:3000 (dashboard: /app)
npm run dev

Or use Docker

docker build -t evalboard .
docker run -p 3000:3000 \
  -e ENCRYPTION_KEY=$(openssl rand -hex 32) \
  -v evalboard-data:/data \
  evalboard

Keep the same ENCRYPTION_KEY forever. If it changes, saved API keys can no longer be decrypted. Demo login after seeding: demo@evalboard.dev / demo-password-123.
